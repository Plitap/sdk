# PLITAP · Инструменты разработчика

Удобный интерфейс для разработчиков совместимых приложений и интеграций.

**Этап:** Опубликована структура направления. Реализация и содержательные материалы будут добавляться отдельными изменениями.

[Карта проекта](https://github.com/Plitap/Plitap/blob/main/REPOSITORIES.md) · [Общие правила участия](https://github.com/Plitap/.github/blob/main/CONTRIBUTING.md)

## Назначение

- Пакеты и привязки к выбранным языкам и платформам.
- Примеры использования протокольных и сетевых возможностей.
- Инструменты разработки и инструкции подключения.

## Границы направления

SDK использует общую реализацию там, где это применимо: [core](https://github.com/Plitap/core), [network](https://github.com/Plitap/network) и компоненты [node](https://github.com/Plitap/node). Он не создаёт собственную конкурирующую спецификацию. Список языков и публичные API пока не зафиксированы.

## Структура

| Раздел | Назначение |
|---|---|
| [`packages/`](packages/) | Будущие пакеты и платформенные привязки. Имена конкретных пакетов определяются вместе с интерфейсами. |
| [`examples/`](examples/) | Небольшие проверяемые примеры интеграции после появления соответствующих пакетов. |
| [`tools/`](tools/) | Инструменты разработчика для работы с опубликованными интерфейсами. |
| [`tests/`](tests/) | Проверки публичных интерфейсов и интеграции SDK. |
| [`docs/`](docs/) | Подключение пакетов, совместимость версий и инструкции разработки SDK. |

Каждый раздел сейчас содержит README с его назначением. Названия разделов не обозначают готовую функцию или выбранную технологию.

## Участие

Вопросы об этом направлении и конкретные задачи — в [Issues](https://github.com/Plitap/sdk/issues). Общие идеи — в [обсуждениях PLITAP](https://github.com/Plitap/Plitap/discussions).

Предложение должно объяснять задачу, ожидаемый результат и связанные компоненты. Рабочее обсуждение, принятое правило и опубликованная реализация имеют разные статусы.

## Условия использования

Лицензии для кода, спецификации и визуальных материалов определяются отдельно. См. [статус лицензирования](https://github.com/Plitap/.github/blob/main/LICENSING.md).
